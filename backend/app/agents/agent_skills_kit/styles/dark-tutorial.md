## When to use

Use this skill when creating educational or tutorial videos where the creator's face is not shown. This style relies on voiceover narration combined with visual elements (screen recordings, stock footage, animations, text) to explain concepts clearly and keep viewers engaged for extended durations (5-30 minutes).

## Core Principles

### 1. Visual Variety Without a Host
- **B-roll is essential**: Use relevant footage, screen recordings, animations, and stock videos to illustrate points. Never have static images for more than 3-5 seconds.
- **Layer multiple visual elements**: Combine screen captures, text overlays, graphics, and occasional presenter shots (silhouette or back-of-head) to create dynamic composition.
- **Use text as a secondary narrator**: Reinforce key points with on-screen text. This aids comprehension and retention.
- **Incorporate visual metaphors**: Use symbolic imagery to explain abstract concepts.

### 2. Pacing for Long-Form Engagement
- **Chunk information**: Break content into 30-90 second segments, each covering one sub-topic. Use visual cues to signal transitions.
- **Vary visual tempo**: Alternate between fast-paced montages and slower, explanatory sequences. This creates a rhythm that prevents fatigue.
- **Strategic pauses**: After complex points, hold on a static visual for 2-3 seconds to let viewers absorb information.
- **Progress indicators**: Use chapter markers, progress bars, or section titles to help viewers track their position.

### 3. Voiceover as Primary Delivery
- **Clear, energetic narration**: Voice should be well-recorded, with good pacing (140-160 words per minute for tutorials). Avoid monotone delivery.
- **Script with visual cues**: Write the script to align with visual changes. Mark where graphics, text, or B-roll should appear.
- **Natural tone**: Sound conversational, not like a lecture. Use contractions and occasional humor.
- **Audio quality is non-negotiable**: Use a decent microphone, record in a quiet environment, and apply noise reduction.

### 4. Text & Graphics Integration
- **Lower thirds for key points**: Display important terms, definitions, or takeaways as animated lower thirds.
- **Call-out boxes**: Use highlighted text boxes for warnings, tips, or important notes.
- **Animated lists**: Reveal bullet points sequentially as you discuss them.
- **Screenshots with annotations**: Circle, arrow, and highlight specific UI elements when demonstrating software.

### 5. Screen Recording Best Practices
- **Resolution**: Record at 1080p or higher. Use a consistent frame rate (30fps or 60fps).
- **Zoom & pan**: Use smooth zoom-ins to focus on specific areas. Avoid static full-screen captures for entire videos.
- **Cursor emphasis**: Enlarge the cursor or add a highlight effect to make it visible.
- **Pre-simplify interfaces**: Hide unnecessary desktop icons, close unrelated windows, use clean browser bookmarks bar.

## Technical Guidelines

### Audio Setup
- **Microphone**: Condenser mic (USB or XLR) with pop filter
- **Sample rate**: 48kHz, 24-bit depth
- **Noise floor**: Record in quiet environment; use noise suppression in post
- **Levels**: Peak between -6dB and -3dB, leaving headroom
- **Compression**: Apply gentle compression (2:1 to 3:1 ratio) to even out volume

### Video Structure Template
1. **Hook (0-30 seconds)**: State the problem or promise a result. Use compelling visuals.
2. **Introduction (30s-2min)**: Overview of what will be covered. Use chapter titles.
3. **Main content (2min-end)**: Divided into clear sections with visual transitions.
4. **Conclusion**: Recap key points. Include call-to-action (like, subscribe, comment).
5. **End screen**: Links to related videos, subscribe button.

### Visual Elements Checklist
- [ ] B-roll footage relevant to topic
- [ ] Screen recordings with zoom/pan
- [ ] Text overlays for key terms
- [ ] Graphics/icons to illustrate concepts
- [ ] Chapter markers/titles
- [ ] Lower thirds for section introductions
- [ ] Animated transitions between sections
- [ ] Background music (low volume, instrumental)
- [ ] Sound effects for emphasis (subtle)

## Common Pitfalls to Avoid

- **Static visuals**: One unchanging image for more than 5 seconds kills engagement.
- **Monotone voice**: Poor narration ruins even the best visuals. Practice delivery.
- **Information overload**: Don't cram too many concepts into one video. Split into parts if needed.
- **Poor audio**: Background noise, echo, or inconsistent volume will make viewers leave.
- **No visual hierarchy**: Text too small, graphics cluttered, or important elements lost.
- **Long rambling intros**: Get to the point quickly. State the value proposition early.
- **Missing context**: Assume viewers know nothing. Explain acronyms and basic concepts.
- **No clear structure**: Jumping between topics confuses viewers. Use clear sections.

## Advanced Techniques

### 1. Storytelling in Tutorials
- **Use real-world examples**: Relate abstract concepts to everyday situations.
- **Create a narrative arc**: Even tutorials benefit from a story: problem → struggle → solution → result.
- **Show failure before success**: Demonstrate common mistakes first, then correct them.

### 2. Visual Reinforcement Strategies
- **Dual coding theory**: Present information both verbally and visually simultaneously for better retention.
- **Progressive disclosure**: Reveal information step-by-step rather than all at once.
- **Comparison shots**: Show before/after, good/bad, old/new side-by-side.

### 3. Engagement Optimization
- **Pattern interrupts**: Every 60-90 seconds, change the visual pattern (switch from screen recording to B-roll, add a graphic, change camera angle if using presenter).
- **Interactive elements**: Pose questions, ask viewers to pause and try, or include polls in description.
- **Emotional hooks**: Share personal anecdotes, surprising facts, or common pain points.

### 4. Accessibility Considerations
- **Clear enunciation**: Speak slowly and clearly for non-native speakers and hearing-impaired.
- **Text redundancy**: Key points should be both spoken and shown as text.
- **High contrast visuals**: Ensure text is readable against backgrounds.
- **Avoid flashing effects**: Can trigger photosensitive epilepsy.

## Workflow Recommendations

1. **Script writing**: Write full narration script with timing notes for visuals.
2. **Storyboarding**: Sketch or list visual elements for each script segment.
3. **Recording**:
   - Record voiceover first (clean audio)
   - Capture screen recordings based on script
   - Gather B-roll and stock footage
4. **Assembly**: Place all clips on timeline synced to voiceover.
5. **Graphics & text**: Add animated text, lower thirds, call-outs.
6. **Color & audio**: Color grade for consistency, mix audio (voiceover, music, SFX).
7. **Review & refine**: Watch through, cut boring parts, adjust pacing.
8. **Export & upload**: Render at appropriate bitrate, add chapters, write description.
